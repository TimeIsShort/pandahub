## 二、P0 核心功能

### 2.1 评论点赞
**目标**：对评论进行点赞，丰富互动维度

**功能**：
- [ ] 数据库加 `comment_votes` 表（user_id / comment_id / type）
- [ ] `comment_votes` 表索引优化
- [ ] `POST /comments/:id/vote` API（点赞/取消）
- [ ] `GET /comments/:id/votes` 获取投票状态
- [ ] 帖子详情页评论区域：👍 按钮显示点赞数
- [ ] 点击即时更新（异步无刷新）
- [ ] 评论点赞不扣积分（免费互动）

**涉及文件**：`routes/comments.js`（新建）、`models/database.js`

## 三、P1 体验增强

### 3.1 黑暗模式
**目标**：一键切换深色/浅色界面，护眼

**功能**：
- [ ] CSS 变量定义深色主题配色
- [ ] 主题切换按钮（顶部工具栏或设置页）
- [ ] 主题状态存储 `localStorage.theme`
- [ ] 页面加载时检测系统偏好 `prefers-color-scheme`
- [ ] 主题切换动画（0.3s 平滑过渡）

**配色方案**：
```
--bg-primary: #0f172a (深蓝黑)
--bg-secondary: #1e293b
--bg-card: #1e293b
--text-primary: #f1f5f9
--text-secondary: #94a3b8
--border: #334155
--accent: #818cf8 (紫)
```

**涉及文件**：`public/css/style.css`、`public/js/app.js`、`public/index.html`

## 四、P2 社交扩展

### 4.1 帖子举报功能
**目标**：用户可举报违规帖子/评论

**功能**：
- [ ] 数据库加 `reports` 表（reporter_id / target_type: post|comment / target_id / reason / status / created_at）
- [ ] `POST /reports` API（需要登录）
- [ ] 帖子详情页加「🚩 举报」按钮（登录用户可见）
- [ ] 评论下方加「🚩 举报」按钮
- [ ] 管理后台新增「🚩 举报管理」Tab
- [ ] 举报列表：举报人 / 被举报内容 / 理由 / 时间 / 操作（忽略/删帖/封禁用户）

**涉及文件**：`routes/reports.js`（新建）、`models/database.js`、`public/js/app.js`、`public/admin-login.html`

---

### 4.2 评论楼内回复嵌套展示优化
**目标**：评论的回复以嵌套样式展示，更直观

**功能**：
- [ ] 当前：评论平铺，回复混在一起
- [ ] 优化：回复缩进并加竖线连接，颜色稍淡
- [ ] 评论卡片内：父评论正常显示，子评论缩进+灰色竖线
- [ ] 嵌套层级限制：最多显示2层，第3层起显示「查看更多回复」
- [ ] 保持性能：大帖子避免递归渲染过深

**涉及文件**：`public/js/app.js`、`public/css/style.css`

## 六、v1.4 开发顺序建议

1. **评论点赞** → 最简单，P0，互动体系补全
2. **黑暗模式** → 用户体验提升明显，工程量适中
3. **个人主页增强（粉丝/关注可点击）** → 小的体验优化
4. **积分排行榜入口优化** → 小的体验优化
5. **帖子举报功能** → 社区运营必备
6. 剩余功能按需推进
