## 二、P0 核心功能

### 2.1 收藏/书签
**目标**：用户收藏感兴趣的帖子，方便日后回顾

**功能**：
- [ ] 收藏按钮（帖子详情页 + 帖子列表）
- [ ] 收藏 API：`POST /favorites`、`DELETE /favorites/:postId`、`GET /favorites`（当前用户）
- [ ] `favorites` 表：`user_id`、`post_id`、`created_at`
- [ ] 个人主页新增「收藏」tab，显示收藏列表
- [ ] 收藏时 Web Push + 邮件通知（可选）

**涉及文件**：`routes/favorites.js`（新建）、`models/database.js`、`public/js/app.js`

---

### 2.2 @提及用户
**目标**：评论时 `@用户名` 可以通知被提及的用户，增强互动

**功能**：
- [ ] 评论内容中解析 `@username` 模式（正则）
- [ ] 提取用户名后查询 user_id，发送通知
- [ ] 通知类型：`mention`，标题 `@username 在评论中提到了你`
- [ ] 前端评论输入框加 `@` 触发用户搜索下拉
- [ ] 同一评论只通知一次（去重）

**涉及文件**：`routes/comments.js`（或 `posts.js`）、`public/js/app.js`

---

### 2.3 通知中心
**目标**：独立通知页面，不只是弹窗，支持历史记录和全部已读

**功能**：
- [ ] 独立通知页面（类似私信列表 UI）
- [ ] 历史通知分页（最近30天）
- [ ] 「全部已读」按钮
- [ ] 通知分类筛选（评论/回复/审核/提及/系统）
- [ ] 每条通知加时间（刚刚/5分钟前/昨天）

**涉及文件**：`routes/notifications.js`、`public/index.html`、`public/js/app.js`

---

### 2.4 帖子编辑/删除
**目标**：作者可以管理自己发布的帖子

**功能**：
- [ ] 编辑按钮（仅作者可见）
- [ ] `PUT /posts/:id` 更新帖子（标题/内容/标签）
- [ ] 删除按钮（确认弹窗）
- [ ] `DELETE /posts/:id`（软删除 or 硬删除）
- [ ] 编辑后重新走敏感词+AI审核流程（或跳过）

**涉及文件**：`routes/posts.js`、`public/js/app.js`

---

### 2.5 积分排行榜
**目标**：首页展示积分排名前10用户，激励用户赚积分

**功能**：
- [ ] `GET /leaderboard` API，返回 top10 用户（积分/昵称/头像）
- [ ] 首页侧边栏或专属 tab 显示排行榜
- [ ] 排名变化标识（↑↓-）
- [ ] 点击用户头像跳转主页

**涉及文件**：`routes/leaderboard.js`（新建）、`public/index.html`、`public/js/app.js`

---

## 三、P1 体验增强

### 3.1 签到历史
**目标**：用户查看历史签到记录，激励连续签到

**功能**：
- [ ] 签到页面新增「签到记录」tab
- [ ] 日历视图：每天一个格子，已签到=绿色，未签到=灰色
- [ ] 月份切换（上月/下月）
- [ ] 连续签到中断时高亮显示断签日

**涉及文件**：`public/index.html`、`public/js/app.js`、`public/css/style.css`

---

### 3.2 搜索优化
**目标**：增强搜索筛选能力，提升内容发现效率

**功能**：
- [ ] 搜索页加筛选器：时间范围（今天/本周/本月/全部）、排序（最新/最热）
- [ ] 按标签筛选（在搜索结果页加标签过滤）
- [ ] 搜索结果高亮关键词
- [ ] 无结果时推荐热门帖子

**涉及文件**：`routes/search.js`、`public/index.html`、`public/js/app.js`

---

### 3.3 用户活跃日历
**目标**：个人主页展示 GitHub 风格的活跃热力图

**功能**：
- [ ] 个人主页新增「活跃」tab
- [ ] 52周网格（一年），每天格子颜色深浅=活跃度
- [ ] 活跃度 = 发帖数 + 评论数 + 签到
- [ ] 悬停显示具体日期+活跃详情
- [ ] API：`GET /users/:id/activity` 返回每日活跃数据

**涉及文件**：`routes/users.js`、`public/js/app.js`、`public/css/style.css`

---

## 四、P2 社交扩展

### 4.1 点赞功能
**目标**：帖子点赞/点踩，热度影响排序

**功能**：
- [ ] 帖子列表和详情页加 👍👎 按钮
- [ ] `POST /posts/:id/vote`（type: like/dislike）
- [ ] `votes` 表：`user_id`、`post_id`、`type`、`created_at`
- [ ] 每人每帖只能投一次，重复投=切换或取消
- [ ] 帖子热度分数 = like - dislike，支持排序

**涉及文件**：`routes/votes.js`（新建）、`models/database.js`、`public/js/app.js`

---

### 4.2 精选/置顶
**目标**：管理员可以置顶精品帖子，提升内容质量

**功能**：
- [ ] 管理后台加「置顶」「加精」按钮
- [ ] `posts` 表加 `is_pinned`（0/1）、`is_featured`（0/1）字段
- [ ] 帖子列表查询时 `is_pinned=1` 排最前
- [ ] 帖子详情页加 🏆置顶 / ⭐加精 标识

**涉及文件**：`routes/posts.js`、`routes/admin.js`、`public/js/app.js`

---

### 4.3 标签管理后台
**目标**：管理员在后台增删改标签和分类

**功能**：
- [ ] 管理后台新增「🏷️ 标签管理」tab
- [ ] 增/删/改标签（名称、颜色、图标）
- [ ] 标签排序（拖拽或上下箭头）
- [ ] 显示每个标签下的帖子数量

**涉及文件**：`routes/admin.js`、`routes/tags.js`、`public/admin-login.html`

## 六、v1.3 开发顺序建议

1. **收藏/书签** → 最简单，用户价值高
2. **积分排行榜** → 上线后用户立刻能看到竞争氛围
3. **帖子编辑/删除** → 基础功能补全
4. **@提及用户** → 增强互动
5. **通知中心** → 历史记录+全部已读
6. **点赞功能** → 热度体系基础
7. 剩余功能按需推进
