## 一、社交体系（用户粘性）

### 1.1 用户个人主页优化
**现状**：用户主页只有基础信息 + 帖子列表<br>
**目标**：完整的个人主页卡片

**功能**：
- [ ] 头像上传（目前用户表有 avatar 字段，未接入上传）
- [ ] 个人简介（bio）编辑
- [ ] 发帖数 / 评论数 / 积分 / 等级徽章展示
- [ ] 注册时间、最近活跃时间
- [ ] 用户的帖子/评论/收藏分类 tab

**涉及文件**：`routes/users.js`、`public/profile.html`（或内嵌 view）

---

### 1.2 关注系统
**目标**：用户之间互相关注，构建社交关系

**功能**：
- [ ] 关注/取消关注按钮
- [ ] 关注列表、粉丝列表
- [ ] 「我的关注」帖子 feed（后续）

**数据库**：
```sql
CREATE TABLE follows (
  follower_id INTEGER,
  following_id INTEGER,
  created_at DATETIME,
  PRIMARY KEY(follower_id, following_id)
);
```

**涉及文件**：`routes/users.js`、`public/js/app.js`

---

### 1.3 私信系统
**目标**：用户之间一对一沟通

**功能**：
- [ ] 发送私信（文字）
- [ ] 私信列表页（会话视图）
- [ ] 未读私信角标
- [ ] Web Push 推送私信通知

**数据库**：
```sql
CREATE TABLE messages (
  id INTEGER PRIMARY KEY,
  sender_id INTEGER,
  receiver_id INTEGER,
  content TEXT,
  is_read INTEGER DEFAULT 0,
  created_at DATETIME
);
```

**涉及文件**：`routes/messages.js`（新建）、`public/js/app.js`

---

## 二、内容体验

### 2.1 富文本发帖编辑器
**现状**：纯文本 textarea，换行靠回车，Markdown 需要手动输入<br>
**目标**：轻量级富文本编辑，体验接近 Notion/Markdown Here

**功能**：
- [ ] 工具栏：加粗、斜体、代码、链接、引用、列表
- [ ] 支持 Tab 键缩进代码块
- [ ] 右下角 Markdown 源码切换开关
- [ ] 草稿自动保存（localStorage）

**技术方案**：基于 `textarea` + 工具栏按钮 + 快捷键（Ctrl+B / Ctrl+I），纯原生实现，不引入大型库

---

### 2.2 帖子收藏/点赞扩展
**现状**：已有 upvote/downvote，收藏功能缺失<br>
**目标**：用户收藏帖子，个人收藏列表

**数据库**：
```sql
CREATE TABLE bookmarks (
  user_id INTEGER,
  post_id INTEGER,
  created_at DATETIME,
  PRIMARY KEY(user_id, post_id)
);
```

**功能**：
- [ ] 帖子卡片/详情页「⭐ 收藏」按钮
- [ ] 个人主页「我的收藏」tab
- [ ] 收藏时 Web Push 通知（可选）

---

## 三、积分经济体系

### 3.1 签到积分优化
**现状**：每日签到一次，+5分固定<br>
**目标**：连续签到奖励机制（连续天数越多积分越高）

**规则建议**：
- 连续 1-7 天：+5 ~ +10 分（递增）
- 连续 8-30 天：+10 ~ +20 分
- 中断后重新从 5 分开始

**涉及文件**：`routes/checkin.js`、`models/database.js`

---

### 3.2 积分排行榜
**目标**：激发用户竞争意识

**功能**：
- [ ] 总积分排行榜（管理后台统计页已有数据）
- [ ] 独立排行榜页面 `/rankings`
- [ ] 展示 TOP20 用户头像 + 积分 + 等级

---

## 四、管理与运营

### 4.1 管理后台数据可视化
**现状**：统计只有数字表格<br>
**目标**：图表化展示趋势

**功能**：
- [ ] 7天/30天 注册用户趋势折线图（用 Chart.js）
- [ ] 帖子发布趋势柱状图
- [ ] 各标签帖子占比饼图
- [ ] 管理员可切换时间范围

**涉及文件**：`admin-login.html`、`routes/admin.js`（`/stats` API 已就绪）

---

### 4.2 邮件通知触发器
**现状**：注册有邮件，审核结果/回复/私信无邮件通知<br>
**目标**：关键事件发邮件提醒

**触发场景**：
- [ ] 帖子审核通过/拒绝 → 发邮件给作者
- [ ] 收到私信 → 发邮件提醒
- [ ] 积分变动（大额扣分）→ 发邮件提醒

**涉及文件**：`routes/posts.js`、`routes/admin.js`、`routes/messages.js`
