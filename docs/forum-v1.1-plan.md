# pandahub.cloud v1.1 功能规划

> 规划版本：v1.1
> 创建时间：2026-03-30
> 优先级说明：🔴 紧急 | 🟡 重要 | 🟢 优化 | 🔵 探索

---

## 一、账号体系（🔴 紧急）

### 1.1 注册登录流程补全
**现状**：注册页面 `register.html` 还是旧版，没有接入邮箱验证码流程；内测申请页面已美化并接验证码<br>
**目标**：用户能自主注册账号（需邮箱验证）

**涉及文件**：
- `public/register.html` - 新增验证码流程（三步 UI）
- `routes/auth.js` - 注册 + 发验证码接口
- `routes/email.js` - 邮件发送逻辑
- `public/css/style.css` - 注册页面样式（复用 apply.html 风格）

**验收标准**：
- [ ] 注册页填写用户名/邮箱/密码 → 发送验证码 → 填验证码 → 提交注册
- [ ] 验证码有效期 5 分钟，超时提示重新获取
- [ ] 注册成功后账号直接激活（`approved=1`），无需管理员审核
- [ ] 密码规则：大写+小写+数字，最少 6 位

---

### 1.2 登录页面美化
**现状**：登录页 `/login` 和注册页 `/register` 共用一套简陋样式<br>
**目标**：与申请页风格统一，三步进度指示器

**涉及文件**：
- `public/index.html` 内的登录弹窗 或 `public/login.html`
- `public/css/style.css`

---

## 二、管理后台体验（🟡 重要）

### 2.1 敏感词管理界面
**现状**：敏感词只能通过 API 增删，管理员操作不便<br>
**目标**：管理后台新增敏感词管理面板

**涉及文件**：
- `admin-login.html` - 新增「敏感词」Tab 页
- `routes/admin.js` - 已有 API：`GET/POST/DELETE /api/admin/word-filter`

**验收标准**：
- [ ] 查看现有敏感词列表
- [ ] 批量添加敏感词（粘贴一批，回车分隔）
- [ ] 单个删除敏感词
- [ ] 操作记录写入 `moderation_log`

---

### 2.2 操作日志查看页
**现状**：API 已有，页面没有<br>
**目标**：管理后台新增「操作日志」Tab 页

**涉及文件**：
- `admin-login.html` - 新增日志 Tab
- `routes/admin.js` - 已有 `/api/admin/moderation-log`

**验收标准**：
- [ ] 分页展示（50条/页）
- [ ] 按动作类型筛选（审核/删帖/封禁等）
- [ ] 显示操作人、时间、目标、内容

---

### 2.3 AI 批量审核体验优化
**现状**：AI 审核按钮已存在，审核进度无反馈<br>
**目标**：审核中显示进度条，完成后统计结果

**涉及文件**：
- `admin-login.html` - 优化 `autoReviewAll` 函数 UI

---

## 三、积分体系完善（🟡 重要）

### 3.1 评论扣积分
**现状**：发帖扣 5 积分，评论未扣<br>
**目标**：评论扣 2 积分，积分不足时提示

**涉及文件**：
- `routes/comments.js` 或 `routes/posts.js`（评论相关路由）
- `models/database.js` - POINT_COST 已有 `create_comment: 2`

**验收标准**：
- [ ] 用户评论前检查积分余额
- [ ] 积分不足返回 403 并提示当前余额
- [ ] 评论成功后扣除 2 积分

---

### 3.2 个人主页显示积分/等级
**现状**：`/api/users/:id` 已返回等级信息，页面展示待优化<br>
**目标**：用户个人主页卡片显示等级图标 + 积分余额 + 连续签到天数

**涉及文件**：
- `public/profile.html` 或内嵌 profile view
- `routes/users.js` - 已接入
- `routes/auth.js` - `/me` 已返回

---

## 四、Web Push 推送落地（🟢 优化）

### 4.1 通知触发 Web Push
**现状**：订阅流程已就绪，但新通知时不触发浏览器推送<br>
**目标**：当用户收到新回复/私信/审核结果时，同步发送 Web Push

**涉及文件**：
- `routes/notifications.js` - 通知创建时调用 `sendPushToUser`
- `routes/comments.js` - 评论通知
- `routes/posts.js` - 审核结果通知

**验收标准**：
- [ ] 用户收到新评论时收到浏览器通知
- [ ] 用户收到审核结果变更时收到浏览器通知
- [ ] 点击通知跳转到对应页面

---

| 优先级 | 功能 | 开发估计 | 理由 |
|--------|------|----------|------|
