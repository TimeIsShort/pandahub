## P0（核心功能）

### 0.1 帖子收藏/书签 ✅ 已完成
**需求**：用户收藏帖子，个人主页展示收藏列表

**实现**：
- `favorites` 表（user_id, post_id, created_at, UNIQUE约束）
- `routes/favorites.js` - POST/DELETE/GET API
- 前端：帖子卡片⭐按钮 + 帖子详情⭐按钮 + 个人主页「收藏」tab：用户收藏帖子，个人主页展示收藏列表

**实现**：
- `favorites` 表（user_id, post_id, created_at）
- `POST /api/favorites/:post_id` 收藏/取消
- `GET /api/favorites` 我的收藏列表（分页）
- 前端：帖子卡片加 ⭐ 收藏按钮 + 个人主页「收藏」tab

---

### 0.2 管理后台 - 帖子审核队列 ✅ 已完成
**需求**：管理员对待审核帖子进行通过/拒绝操作

**现状**：后端API + 管理后台UI已完整实现（审核Tab + badge数量 + 通过/拒绝按钮 + 拒绝原因）

**实现**：
- `GET /api/admin/pending-posts` 审核列表
- `POST /api/admin/posts/:id/approve` 通过
- `POST /api/admin/posts/:id/reject` 拒绝（可选理由）
- `posts` 表新增 `status: pending/approved/rejected` + `rejected_reason`
- 管理后台新增「审核」Tab（badge 显示待审数量）

## P1（体验增强）

### 1.1 移动端底部导航栏 ✅ 已完成
**需求**：手机用户有固定的底部导航（首页/AI/通知/我的）

**实现**：固定底部4栏导航（🏠首页 | 🤖AI助手 | 🔔通知 | 👤我的），≤768px显示，点击激活态同步，通知Badge同步

**实现**：
- 移动端（≤768px）底部固定导航栏
- 图标：🏠 首页 | 🤖 AI | 🔔 通知 | 👤 我的
- 已登录显示，未登录仅首页+AI

---

### 1.2 移动端图片上传体验优化
**需求**：手机上传图片有更好的预览和交互

**实现**：
- 多图选择支持
- 上传进度条
- 上传完成预览缩略图

---

### 1.3 用户个人主页 UI 优化
**需求**：个人主页信息更丰富，展示更美观

**实现**：签到热力图(已有) + 💰积分趋势迷你柱状图(近30天，含签到+转账数据) + 个人主页Tab(post/activity/favorites三栏)

**实现**：
- 签到日历热力图
- 积分获取趋势迷你图
- 帖子/收藏/粉丝/关注 Tab 切换
